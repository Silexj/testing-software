# Учебный аппаратный профиль

Источники перенесены из лабораторной 5, commit bbf165a. Подробное описание:
[аппаратный профиль лабораторной 5](https://github.com/Silexj/testing-software/tree/lab5-redfish-pytest/lab5/stand).

Для Jenkins сборка ARM-модулей выполняется установленным в контейнере
`arm-linux-gnueabi-gcc/g++`. setup_qemu_lab.py скачивает libsystemd из самой
запущенной прошивки и вызывает build.sh. Вложенный Docker не используется.
Проверка точного образа Romulus и осторожные проверки таблицы IPMI сохранены.

Модель PSU/FSI/VRM позволяет штатным state-manager достигать целей systemd.
Штатный phosphor-hwmon читает управляемые значения 42/44 °C. Association.Definitions
связывает их с chassis. Совместимость IPMI исправляет масштаб двух статических
записей с -3 на 0 для современного интерфейса Celsius.

API и показания HTTP/IPMI не подменяются. Физические датчики и загрузка POWER9
не проверяются; это явно заданная конфигурация учебного QEMU.
